Get Firefox.

Posted on December 7, 2004 by Scott Wickstein
Posted in Uncategorised

Comments boxes not working? You might be using crap software. Thanks to ace technical consultant boynton, I learn that the cause of the comments box thing being forbidden is that users are using Internet Explorer!

Oh, the shame!

Get Real. Get Firefox!

Of course, if you MUST use internet explorer, you can still access comments through the date stamp!

(Blimey I had all these people complaining about not being able to access comments, and it turned out they were using the wrong browser. I thought there was something wrong with the site!)

UPDATE- Yes, I know there is something wrong, I just do not know how to fix it.
