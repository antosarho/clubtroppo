# Club Troppo Substack Import Pack

This directory contains a full-post RSS feed and a CSV manifest generated from the SQL-backed static Club Troppo rebuild.

Suggested Substack import path:

1. In Substack, open `Settings -> Import/Export -> Import posts`.
2. Paste the public RSS URL for `feed.xml`.
3. Import the posts.

Files:

- `feed.xml`: Full RSS feed with complete post bodies.
- `posts.csv`: Manifest of all published posts for cross-checking.
- `summary.json`: Totals for the generated import pack.
